## SASL reference asset inventory\n\nThis folder is reserved for local SASL demonstration assets. The current repository does not include verified SASL recordings or images, so this structure intentionally tracks the vocabulary and metadata without claiming full sign-language accuracy.\n\nEach item should be reviewed and supplied by a qualified SASL educator or signer before being used in a production or education demo.\n\n### Candidate vocabulary\n- hello\n- good_morning\n- thank_you\n- please\n- yes\n- no\n- help\n- water\n- hungry\n- happy\n- unwell\n- goodbye\n\n### Metadata schema\nEach local asset should include:\n- label\n- source\n- verification_status\n- media_type (image|video)\n- notes\n\nThis keeps the demo local and prevents external image dependencies.\n
